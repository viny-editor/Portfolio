# Portfólio · Vinicius

Site estático (HTML único, sem build).

- `index.html` → versão em inglês (raiz do site)
- `pt/index.html` → versão em português (`/pt/`)

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `portfolio`).
2. Envie TODO o conteúdo desta pasta para a raiz do repositório (inclusive `.nojekyll`).
3. No repositório: Settings → Pages → Build and deployment → Source: "Deploy from a branch" → Branch: `main` / pasta `/ (root)` → Save.
4. Espere 1 a 2 minutos. O site fica em `https://SEU-USUARIO.github.io/portfolio/` e a versão em português em `.../portfolio/pt/`.

## Editar depois
